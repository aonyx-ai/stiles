# stiles check --help

```console
$ stiles check --help
Run stiles lints against a project

Usage: stiles[EXE] check [OPTIONS] [PATH]

Arguments:
  [PATH]  Path to the target project directory [default: .]

Options:
      --keep-going     Continue checking after encountering errors
      --deny-warnings  Treat warnings as errors
      --fix            Apply the fixes of the findings, and report the findings that remain
  -q, --quiet          Suppress informational messages
  -v, --verbose        Show additional detail
      --json           Output results as JSON
  -h, --help           Print help

```
